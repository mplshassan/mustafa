Polarity

A web app that draws polar charts of NBA player game performance. It pulls live and historical data back to 1947 from the NBA Stats API and matches player names loosely. Single mode shows one player; Flux mode compares two, with stats scaled against per-game highs.

May 2026. Python, Streamlit, Plotly, nba_api

A sentence-level sentiment analysis app. Type free text, or enter one sentence at a time. VADER and NLTK score each sentence, and an interactive Plotly chart shows the scores as you go.

Markov Polo

A real-time tracking game built on a predict-update Bayesian filter over a 484-cell probability grid, with no math libraries. Noisy distance readings are modeled with Gaussian-approximated randomness, and a live canvas heatmap shows the belief and its entropy.

Jul 2026. JavaScript, HTML5 Canvas
